📡 API Endpoints
🔐 Permisos
Listar todos los permisos
GET → http://localhost:8080/api/permiso

Detalle de un permiso
GET → http://localhost:8080/api/permiso/{id}

Crear permiso
POST → http://localhost:8080/api/permiso

Modificar permiso
PUT → http://localhost:8080/api/permiso/{id}

Eliminar permiso
DELETE → http://localhost:8080/api/permiso/{id}
